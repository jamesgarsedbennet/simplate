# How to host SimPlate

The site is static: `index.html`, `styles.css`, `panel.js`, `earcut.min.js`, `logo.png`.
No server. STL files are generated in the visitor’s browser.

Buy Me a Coffee is `https://www.buymeacoffee.com/simjim`.

## GitHub Pages

1. Repo → Settings → Pages.
2. Source: Deploy from a branch.
3. Branch: `main`, folder: `/ (root)`. Save.
4. Site: `https://jamesgarsedbennet.github.io/simplate/`

Optional custom domain in Pages settings.

## Netlify drop

Drag the `simplate` folder onto https://app.netlify.com/drop
