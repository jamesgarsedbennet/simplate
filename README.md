# SimPlate

Browser tool that builds blank home-cockpit panel STLs. No login. Files are generated on your machine.

Live on GitHub Pages after you enable it:

`https://jamesgarsedbennet.github.io/simplate/`

## Files

- `index.html` — page
- `styles.css` — layout
- `panel.js` — preview + STL mesh
- `earcut.min.js` — triangulation
- `logo.png` — Sim Jim mark
- `HOSTING.md` — Pages / Netlify steps

## GitHub Pages

Repo → Settings → Pages → Deploy from a branch → `main` / root.
